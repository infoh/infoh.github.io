### **Windows XP 专业版：C 盘子目录共享完整实操案例**

案例环境：Windows XP Professional，NTFS 格式 C 盘；新建共享目录：C:\LanShare，网络共享名：LanShare；目标：局域网其他电脑只读访问，不能修改删除文件。
⚠️只共享这个自建文件夹，不会泄露 C 盘其他系统文件。

##### **步骤 1：新建目标文件夹**

打开我的电脑→C 盘根目录，空白处右键【新建‑文件夹】，命名：LanShare
路径完整：C:\LanShare，把需要对外的文件复制到此文件夹。

##### **步骤 2：关闭简单文件共享（高级权限模式，推荐）**

打开任意文件夹顶部菜单：工具 → 文件夹选项 → 查看
滚动到底部，取消勾选【使用简单文件共享 (推荐)】 →确定
取消后文件夹属性会出现【共享】、【安全】两个标签；
如果保持勾选简单共享，只能用 Guest 来宾模式，无法精细化账号权限。

##### **步骤 3：开启文件夹共享**

右键 C:\LanShare →【共享和安全】，切换到共享选项卡
勾选：共享此文件夹
共享名：LanShare（网络访问时使用这个名字，可以和本地文件夹名不一样）
点【权限】按钮
默认有Everyone，只勾选读取，取消 “更改、完全控制”（实现只读）
确定保存【共享权限】。
✅共享权限只是第一道关卡；NTFS 安全权限是第二道，远程访问取两者交集，两处都要放行。

##### **步骤 4：配置 NTFS 安全权限（C 盘子目录最容易踩坑）**

切换到【安全】标签（关闭简单文件共享才会出现）
检查列表，确保Everyone或者你用来登录的账号存在；
选中账号，权限只勾选：读取 & 列出文件夹内容，不要勾选修改、写入；
点【高级】→勾选：用在此显示的可以应用到子对象的项目替代所有子对象的权限项目，点确定。
C 盘继承系统目录 ACL，如果不做这一步，远程访问直接报【拒绝访问】。

##### **步骤 5：防火墙放行**

控制面板 → Windows 防火墙 →【例外】标签 → 勾选 文件和打印机共享，确定。
防火墙拦截，会提示 “找不到网络路径”。

##### **步骤 6：确认 XP 本机 IP 地址**

开始‑运行输入 cmd，执行：
cmd
ipconfig
假设 XP 本机局域网 IP：192.168.1.105

##### **步骤 7：别的电脑访问该共享**

在另一台电脑【开始‑运行】输入 UNC 路径：
plaintext
\\192.168.1.105\LanShare
输入 XP 的管理员账号和密码（账号必须设置密码，空密码 XP 拒绝网络登录），打开，只能读取，不能修改文件。

### **案例 B：来宾 Guest 模式（开启简单文件共享，适合无需账号密码访问）**

工具‑文件夹选项‑查看，勾选【使用简单文件共享】
控制面板‑用户账户，开启Guest来宾账户
右键 C:\LanShare‑共享和安全，勾选 “在网络上共享这个文件夹”
不要勾选 “允许网络用户更改我的文件”（只读）
其他电脑直接输入\\192.168.1.105\LanShare，无需密码直接读取。
缺点：全部网络用户统一权限，不能区分不同账号。

### **常用排错（C 盘子目录高频报错）**

##### 拒绝访问

NTFS 安全标签没有给账号读取权限；
使用管理员账号访问时，该账号密码为空，XP 禁止空密码网络登录；
本地安全策略secpol.msc，“拒绝从网络访问这台计算机” 里面有 Guest，需要删除。

##### 找不到网络路径

ping XP 的 IP 是否通；防火墙未放行；Server 服务未启动。
开启服务：运行输入services.msc，找到Server，启动类型自动，启动服务。
文件夹属性显示灰色只读
XP 文件夹 UI 的灰色只读标记是正常现象，不影响网络共享读写，不用处理。

##### 安全要点

仅限内网局域网，严禁把 139/445 端口映射公网，XP 无安全补丁。
C:\LanShare不要放在 Windows、Program Files、Documents and Settings 内部，放在 C 盘一级目录。
用完后取消文件夹共享；不要长期开启。
本案例是普通文件夹共享，不是 C$ 管理共享，不会开放整个 C 盘。

##### 查看本机所有共享（cmd）

cmd
net share
可以看到LanShare已经列为共享资源。
取消共享：右键文件夹，取消勾选 “共享此文件夹”。
