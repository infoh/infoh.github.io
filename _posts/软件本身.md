### 使用 Claude Code 通过云端 API 访问 DeepSeek 大模型

Claude Code 是一款基于 VS Code 的 AI 编程插件，能够帮助编程新手通过自然语言指令进行代码编写与调试，实现 “Vibe Coding”。

第一步：1、安装Node.js（v18+版本必备）
Claude Code 基于 Node.js 开发，必须安装v18及以上版本，低版本会直接安装失败。下载地址：https://nodejs.org/en/download/

安装完成后，验证是否成功：打开CMD命令提示符（管理员身份运行更佳），输入命令：
node -v
npm -v

如果返回类似v24.13.0 和11.6.2的版本号类似的，说明安装成功。

第二步：2、注册智谱GLM并获取API Key（国内访问核心）
Claude Code官方服务国内无法直接访问，这里我们通过智谱GLM的Coding Plan做跳转，不仅能国内直连，还能以更低的成本使用，性价比拉满。

智谱GLM注册地址：https://www.bigmodel.cn/invite?icode=ktd3FDLmLGsCwT7yHw3uXn3uFJ1nZ0jLLgipQkYjpcA%3D
https://open.weixin.qq.com/connect/confirm?uuid=091oTsZx2T7tll29 (二维码自动识别)

注册登录后，点击进入「API Keys」页面，https://www.bigmodel.cn/usercenter/proj-mgmt/apikeys

点击「添加新的APIKey」，直接创建专属API Key，复制好保存到记事本，后续会多次用到（注意：API Key格式为id.secret，不要泄露给他人）。

第三步：3、安装Coding Tool Helper（API配置神器）
这是一个专门的编码助手，能自动把智谱GLM的API加载到Claude Code中，省去手动配置环境变量的麻烦，新手必装。

打开CMD，直接输入命令，回车后自动安装并启动配置界面：npx @z_ai/coding-helper
启动后会看到可视化配置界面，按照提示依次选择：界面语言（中文）→编码套餐（GLM Coding Plan中国版）→API Key，把刚才复制的智谱API Key粘贴进去，确认后就配置完成了，界面会显示「API Key：已设置」。

第四步：4、正式安装Claude Code


前期准备全部搞定后，安装Claude Code就一步到位，全程30秒左右。

保持CMD为管理员运行状态，输入官方安装命令，全局安装Claude Code：
npm install -g @anthropic-ai/claude-code

等待命令执行完成，提示「changed X packages in XXs」就是安装成功，无需额外操作。

输入以下命令，检查Claude Code版本：claude --version
如果返回类似2.1.21 (Claude Code)的版本号，说明安装成功，接下来就是配置和启动了。

实用小技巧：跳过反复权限确认


如果觉得开发过程中Claude Code反复询问是否创建文件、修改代码太麻烦，可以在启动时添加一个参数，直接跳过所有权限确认（注意：此操作有一定风险，仅在自己的工作目录中使用，不要在系统目录、敏感文件夹中使用）。

启动命令改为：

claude --dangerously-skip-permissions
启动后，Claude Code会直接进入交互界面，后续所有文件操作、代码修改都会自动执行，无需手动确认，开发效率拉满。
